# حجات ممكن تحفظها لانها خصائص HTML Attribute

class مسمي لملف الاستايل
placeholder الاسم اللي جوا الحقل
name عشان تربط الحقول ببعض
type الحقل عباره عن ايه
target اللينك يفتح جوا الصفحه ولا برا الصفحه



# حجات ممكن تحفظها لانها قيم CSS Values
cover تاخد شكل الكونتينر كلو
fixed الحاجه ثابته مكانها
scroll الحاجه بتتحرك معاك وانت رايح وجي



# حجات ممكن تحفظها لانها خصائص CSS Properties
